- Source: https://github.com/hckiang/font-new-heterodox-mono

- Archive: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/Inconsolata.tar.xz
- Archive SHA-256: `be1903b0016d398e3dc5b25814438b8d0fa44ca9e0ac5d9775130f406345d586`
- Files: `inconsolata-nerd-font-mono/InconsolataNerdFontMono-Regular.ttf` and `inconsolata-nerd-font-mono/InconsolataNerdFontMono-Bold.ttf`
- Only the Mono variants are bundled, not the standard or Propo variants.

Neither bundled family includes an italic face.
